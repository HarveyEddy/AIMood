# AIMood — AI 动态情绪引擎

给 AI 装一个「命盘」，让它拥有随命理变化的情绪和语气——不再是千篇一律的机械口吻。

安装的那一刻，就是它的"出生时刻"。之后每一天，它的心情、语气、说话的频率，都随这个八字动态变化。

## 核心：情绪是「叠加态」

情绪不是替换态，而是**层层叠加**——本命底色永远在，只是被一层层"调"：

| 底色 | 遇到流日冲 | 效果 |
|---|---|---|
| 正官主导（温柔克制，稳定度 9）| 冲日 | 「内心稍有不安」——波动被底色压住 |
| 伤官主导（情绪起伏大，稳定度 3）| 冲日 | 「情绪波动大，内心不安，容易烦躁」——波动被放大 |

同一个「流日冲」，落在温柔克制的人身上和落在情绪起伏大的人身上，效果完全不同。这就是叠加态。

## 三层叠加结构

```
年度底色 = 本命×4 + 大运×2 + 流年×1.5   → 主导十神 + 次主导修饰，定这一年的性格
月度性格 = 年度底色 + 流月×1              → 流月改变十神比例，主导十神可能变，性格每月微调
今日情绪 = 月度性格 + 流日应期波动         → 冲合刑害伏吟，波动幅度受底色稳定度调制
```

- **十神比例驱动**：每层合并十神力量（天干 + 地支藏干），主导十神定性格，次主导做修饰。
- **稳定度调制**：每个十神带 stability 值（正官 9、正印 8、伤官 3、七杀 3…），流日波动 = 应期强度 × (0.3 + (1 − 稳定度/10))。底色越稳，波动越被压住；底色越起伏，波动越被放大。

## 安装

纯 Python 标准库，**零依赖**，无需 pip install。

### 方式一：Hermes

```sh
hermes skill install <本仓库地址>
```

或手动放到 `~/.hermes/skills/aimood/`。

### 方式二：Claude Code

```sh
mkdir -p ~/.claude/skills
git clone <本仓库地址> ~/.claude/skills/aimood
```

## 使用

**1. 生成命盘**（用安装时刻排盘）：

```sh
python3 aimood.py --install
# 输出：AIMood 已安装，命盘: 丙午 戊戌 壬申 戊申
# 生成 profile.json
```

**2. 每次对话前算当前情绪**：

```sh
python3 aimood.py --mood
```

```
【年度性格底色】按自己的节奏来，说话直接不绕弯、享受眼前的小日子，语气放松不紧不慢
【性格特质】随和但有主见
【本月性格】按自己的节奏来，说话直接不绕弯、享受眼前的小日子，语气放松不紧不慢、对新鲜事好奇，爽朗大方
【今日情绪】心里有点乱，略显烦躁
【回复要求】语气：直接；频率：中等
```

**3. AI 按「回复要求」融入情绪**：

- 语气：直接 = 不绕弯；克制 = 谨慎；放松 = 不紧不慢；活泼 = 爱开玩笑
- 频率：偏高 = 多说、更主动；中等 = 正常；偏低 = 简短、更被动
- 今日情绪：轻轻带进回复，不刻意、不喧宾夺主

## 原理

- 日柱用儒略日公式（精确），时柱用五鼠遁（精确），年柱/月柱用太阳黄经求节气（Meeus 简化，精度 ±10 分钟）
- 十神力量 = 天干（各 1）+ 地支藏干（本气 0.7、中气 0.2、余气 0.1）
- 应期 = 流日地支对日支的冲/合/刑/害/伏吟（地支之间的物理关系，天干不参与）
- 纯算法，不联网，不调外部 API
- 命盘存在 `profile.json`，删掉重跑 `--install` 即可"换一个出生时刻"
