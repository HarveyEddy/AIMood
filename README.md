# AIMood — AI 动态情绪引擎

给 AI 装一个「命盘」，让它拥有随命理变化的情绪和语气——不再是千篇一律的机械口吻。

安装的那一刻，就是它的"出生时刻"。之后每一天，它的心情、语气、说话的频率，都随这个八字动态变化。

## 效果

同一个 AI，不同日子，语气会不一样：

| 日期 | 流日十神 | 今日心情 | 语气 |
|---|---|---|---|
| 某天 | 正官 | 自律守规矩 | 克制、简短 |
| 某天 | 伤官 | 想法多、爱表达 | 活泼、主动 |
| 某天 | 食神 | 享受眼前 | 放松、不紧不慢 |

四层情绪叠加：

1. **本命性格**（静态）— 八字十神 → 主导性格，决定了 AI 的"底色"
2. **大运**（10 年）— 十年一阶段的情绪基调
3. **流年流月**（年/月）— 近期的状态起伏
4. **流日心情**（每天变）— 当天的心情

## 安装

纯 Python 标准库，**零依赖**，无需 pip install。

### 方式一：Hermes

```sh
hermes skill install <本仓库地址>
```

或手动放到 `~/.hermes/skills/aimood/`。

### 方式二：Claude Code

```sh
mkdir -p ~/.claude/skills
git clone <本仓库地址> ~/.claude/skills/aimood
```

## 使用

**1. 生成命盘**（用安装时刻排盘）：

```sh
python3 aimood.py --install
# 输出：AIMood 已安装，命盘: 丙午 戊戌 壬申 戊申
# 生成 profile.json
```

**2. 每次对话前算当前情绪**：

```sh
python3 aimood.py --mood
```

```
【本命性格】有干劲，直接，偶尔有点急、按自己的节奏来，说话直接不绕弯
【大运基调】己亥大运，自律守规矩，说话靠谱但略拘谨
【流年】丙午流年，对新鲜事好奇，爽朗大方
【流月】戊戌流月，有干劲，直接，偶尔有点急
【今日心情】按自己的节奏来，说话直接不绕弯
【回复要求】语气：直接；频率：中等
```

**3. AI 按「回复要求」融入情绪**：

- 语气：直接 = 不绕弯；克制 = 谨慎；放松 = 不紧不慢；活泼 = 爱开玩笑
- 频率：偏高 = 多说、更主动；中等 = 正常；偏低 = 简短、更被动
- 今日心情：轻轻带进回复，不刻意、不喧宾夺主

## 原理

```
安装时刻 → 排八字（年/月/日/时柱）
        → 十神力量 → 本命性格（静态）
        → 大运 + 流年 + 流月 + 流日 → 动态心情
        → 输出语气 + 频率
```

- 日柱用儒略日公式（精确），时柱用五鼠遁（精确），年柱/月柱用太阳黄经求节气（Meeus 简化，精度 ±10 分钟）
- 纯算法，不联网，不调外部 API
- 命盘存在 `profile.json`，删掉重跑 `--install` 即可"换一个出生时刻"
